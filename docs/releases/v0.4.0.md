# mcptunnel v0.4.0 — keep browser state between calls

Opt in with `mcptunnel --keep-alive -- npx -y @playwright/mcp@0.0.84 --browser chrome --headless --isolated`. Separate modern HTTP calls can navigate and then use the same open page. Existing mounts keep the per-request default.

- `--keep-alive` preserves modern upstream state per mount and authenticated Basic owner or OAuth issuer/subject/scope set. Existing mounts and ordinary modern calls retain the per-request default; legacy initialized sessions are unchanged.
- Retained contexts admit one operation each and share bounded capacity with legacy sessions. Same credentials on one mount share state; create separate mounts for independent workflows. Upstream filesystem/profile isolation remains the server operator's responsibility.
- `reset <mount> [--json]` clears retained state for all owners while preserving the URL, credentials and legacy sessions. Expiry, fatal or uncertain upstream failure and daemon restoration produce an explicit state-loss error; no mutating call is automatically replayed.
- CLI capability preflight refuses older daemons before creating a retained mount. DB/JSON/IPC defaults preserve old behavior. `inspect` and `doctor` show sanitized retained state without starting a duplicate server.

Focused local verification on macOS with Rust 1.88.0 and existing Node/Chrome:

- Counter continuity across modern calls and intervening discovery, separate mounts, default isolation, authentication/policy denial and nullable optional tool fields.
- Locally signed OAuth subject/scope isolation, including canonical scope ordering; no external authorization-server login was performed.
- Initial startup failure capacity release, idle/hard expiry, active-call idle protection, ordinary error retention, crash/cancellation loss, reset, shared legacy quota and owned-process cleanup.
- Default-off DB migration, invalid stored lifetime rejection and old-daemon CLI refusal.
- Existing legacy-session/default-stateless regressions and descendant cleanup.
- Real `@playwright/mcp@0.0.84` over Basic-authenticated localhost MCP `2026-07-28`: `browser_navigate`, then a separate `browser_evaluate` reads the same URL and in-memory page nonce. Reset reduces retained contexts from one to zero; the test daemon exits and disposable state is removed.
- Formatting and strict all-target Clippy.

Reproduce the browser flow with an installed 0.4.0 binary:

```sh
node scripts/verify-keep-alive.mjs "$(command -v mcptunnel)" /tmp/mcptunnel-browser-result.json
```

The runner uses an isolated browser profile, task-owned daemon configuration/state, and one owned loopback page. Detailed run output belongs outside the repository. The browser result is gateway-to-real-browser wire evidence. Account-backed AI-client E2E, external OAuth login, browser continuity through public Quick Tunnel and optional interactive MCP features were not verified by that check.
