# mcptunnel v0.2.3

Install mcptunnel without Rust or Cargo. Native archives are available for Windows x64, macOS Intel/Apple Silicon, and Linux x64/ARM64, with SHA256SUMS.

- PowerShell and shell installers download the matching executable and install Cloudflare's official cloudflared 2026.10.0 if missing. Checksums are verified before installation; no administrator access is required.
- The quick start uses the real official Filesystem MCP 2026.8.31, restricted to directory listing and text reads in a dedicated shared directory.
- Publication requires the existing Rust/protocol CI and installation plus real Filesystem MCP tests on every release target.

Windows ARM64 can use the x64 binary under OS emulation; no native Windows ARM64 binary is provided. Linux requires OpenSSL 3 and glibc 2.35+ on x64 (Ubuntu 22.04+) or 2.39+ on ARM64 (Ubuntu 24.04+). MCP server runtimes, such as Node.js, are installed separately.

Quick URLs remain temporary. Modern operations use one isolated upstream process per request; legacy sessions preserve process state. Full protocol conformance and actual AI-client certification are not claimed. See the README and engineering report for supported operations and limits.
