# mcptunnel v0.3.7

First public release of the synchronous stdio-to-HTTP MCP bridge.

- Run existing MCP servers on localhost, or add `--public` for temporary Cloudflare HTTPS. Basic authentication is enabled by default.
- Use independent paths and ports with persistent mount configuration and isolated local/public routing.
- Start with a pinned, read-only Filesystem example; runtime and modern in-memory state limits are explicit.
- Legacy cancellation reaches active requests within the authenticated session, with typed request IDs and cleanup.
- `doctor` distinguishes local health, provider announcement, DNS and public HTTP reachability.
- Native archives and checksum-verifying installers cover Windows x64, macOS Intel/ARM64 and Linux x64/ARM64.

The integrated runtime passed 70 local Rust tests, strict lint, real routing/Filesystem checks and one actual Codex CLI 0.146.0 Basic-authenticated connection. Publication is gated by the three-OS verification, selected supported conformance scenarios, and five native build/installer/Filesystem jobs.

Scope: synchronous tools/resources/prompts/completion and supported legacy sessions. Modern requests start a fresh upstream process. Quick URLs are temporary and do not support SSE. Full optional/interactive MCP conformance and managed hosting are not supported. Browser OAuth and additional named-client combinations remain unverified.

See [installation and usage](../USER_GUIDE.md), [client evidence](../CLIENT_COMPATIBILITY.md), and the [pre-release audit](../PUBLIC_READINESS.md).
