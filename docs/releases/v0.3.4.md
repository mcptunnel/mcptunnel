# v0.3.4 — public endpoint diagnostics

`mcptunnel doctor <mount>` separately reports local health, provider URL announcement, system DNS and public HTTP reachability. A URL announcement no longer stands in for connectivity evidence. DNS and HTTP failures give specific retry/resolver/routing instructions without changing DNS, mounts or provider processes.

Health probes carry no credentials, do not follow redirects, and use bounded DNS/HTTP timeouts. Focused tests cover health results, redirects, credentials and connection errors. Tracked in [td#602](https://tdtd.dev/602). Unpublished.
