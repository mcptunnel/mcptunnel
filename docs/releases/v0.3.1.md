The macOS/Linux installer now configures persistent PATH automatically. Users can open a new terminal and run `mcptunnel` without editing a shell profile or copying a PATH export.

- Preserve existing PATH entries and profile content. Reinstalling does not duplicate entries; relocating the installation updates the shared activation files.
- Configure zsh login/interactive startup (including custom ZDOTDIR), bash login/interactive startup without shadowing existing login files, fish conf.d with XDG_CONFIG_HOME, and POSIX login profiles.
- Print an optional source command for the current terminal. Add `MCPTUNNEL_NO_PATH=1` to opt out of profile changes.
- Reject install directories with PATH separators or line breaks. Continue verifying archive checksums and binary versions before installing or editing shell configuration.
- Exercise native shell startup with real release archives in isolated homes, covering quoting, existing PATH, repeated activation/reinstall, relocation, read-only profiles, opt-out and corrupt archives. Linux candidates also verify fish; macOS candidates verify the default zsh on Intel and Apple Silicon.
