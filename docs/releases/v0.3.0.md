mcptunnel now serves stdio MCP on localhost by default. Add `--public` to open a temporary Cloudflare Quick HTTPS URL.

- `--public`, `--port` and `--path` work in the bare command and `run` form. Default port is 8000; a custom `daemon.bind` supplies an alternate daemon default.
- Paths follow server/package names, with automatic suffixes for inferred collisions. Explicit paths are exact and duplicates on the same port fail. Different ports can use the same path.
- Same-port mounts share a listener. Public mounts on each port share a separate filtered ingress/provider, excluding local-only routes, inspection and OAuth metadata.
- Mount ports, paths and visibility survive restart. Existing mounts retain their old port and `/slug/mcp` path. Last-public removal reaps its provider; last-mount removal closes the listener.
- Registration rolls back on port, probe or initial provider failure. Status/inspection now report listeners and `url`/`local_url`; `public_url` is null for local mounts. Legacy `--tunnel quick` remains an explicit exposure choice; legacy global quick config does not expose new mounts automatically.
- Windows package launchers such as `npx` resolve automatically. README starts with the official Filesystem MCP and includes localhost/public output examples.

Validation: Rust tests, strict Clippy/fmt/release build, real CLI/HTTP/stdio routing checks, 50 supported official conformance scenarios, and the real official Filesystem MCP over local HTTP and public Quick HTTPS. Account-backed AI-client and external OAuth browser flows remain unverified. Full MCP conformance still has documented unsupported feature failures; managed hosting remains unavailable. See the engineering report for current platform/candidate results.
